# Yogesh Mehra - Java Backend Developer Portfolio

A premium, production-quality personal portfolio website built with React, TypeScript, and Three.js.

## Tech Stack

- **React 18** - UI library
- **TypeScript** - Type safety
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Three.js** - 3D graphics
- **React Three Fiber** - React renderer for Three.js
- **Drei** - Three.js helpers for React
- **Framer Motion** - Animations
- **Lucide React** - Icons

## Features

- Interactive 3D backend architecture visualization
- Animated counters for metrics
- Scroll-triggered animations
- Responsive design
- Premium dark theme
- Production systems showcase
- Security architecture flow
- Experience timeline

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

```
src/
├── components/       # Reusable UI components
├── sections/         # Page sections
├── three/           # 3D components
├── hooks/           # Custom React hooks
├── App.tsx          # Main app component
├── main.tsx         # Entry point
└── index.css        # Global styles
```
